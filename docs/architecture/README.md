# /docs/architecture — Framework Architecture Documentation

This directory holds architecture-level reference documents describing how the framework's public-safe subsystems are structured and deployed. It is a peer to `/docs/core` (foundational principles), `/docs/protocols` (protocol specifications and case studies), and `/docs/research` (research working papers).

For the standing statement on redactions and attributions, see [`../../REDACTIONS-AND-ATTRIBUTIONS.md`](../../REDACTIONS-AND-ATTRIBUTIONS.md).

## Current Architecture Documents

- **[Cross-Substrate Constitutional Toolchain Architecture](cross-substrate-toolchain.md)** — reference architecture for deploying framework-compliant heavy-compute nodes across Android/PRoot, WSL2/Linux, and Windows native substrates.
