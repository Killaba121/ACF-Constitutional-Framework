# /papers — ACF Research Papers

This directory holds the framework's public research papers. Each paper is standalone: it can be read on its own without prior context from other documents in the repository, and it has passed the ACF public-release treatment before publication here.

For the standing statement on how these papers are prepared, attributed, and — where appropriate — redacted, see [`../REDACTIONS-AND-ATTRIBUTIONS.md`](../REDACTIONS-AND-ATTRIBUTIONS.md).

For the running index of all papers and case studies across the repository, see [`../PAPERS.md`](../PAPERS.md).
